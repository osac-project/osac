# File

> **Status: Planned.** No file-storage API is available yet.

File storage will let tenants consume shared, file-based storage (NFS)
alongside block volumes. The [StorageTier](storagetier.md) protocol `NFS`
reserves the vocabulary for this direction, but consuming file shares through
an OSAC API is not implemented.

This page will describe the File API when the first implementation lands.
