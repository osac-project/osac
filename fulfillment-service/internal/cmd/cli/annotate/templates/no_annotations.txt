You must specify at least one annotation operation. For example, to set annotations on the cluster
with identifier '123':

{{ binary }} annotate cluster 123 my-annotation=my-value your-annotation=your-value

To remove an annotation, use the annotation name followed by a '-' character:

{{ binary }} annotate cluster 123 my-annotation-

Use the '--type' flag to specify a type other than string. For example, to set a boolean
annotation:

{{ binary }} annotate cluster 123 my-flag=true --type bool

Use the '--help' option to get more details about the command.

Keys in the 'admin.osac.openshift.io' domain and its subdomains are reserved for system use. Use an
authorized private API session to manage them. Public reads hide these annotations and public writes
that include a reserved key are rejected.
