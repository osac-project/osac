# NetApp

> **Status: Dev Preview (CSP-managed).** NetApp is the provider of the
> CSP-managed Dev Preview profile. OSAC-managed NetApp support is planned.

NetApp storage is integrated through ONTAP and the Trident CSI driver.

This page is being expanded with:

- ONTAP and storage virtual machine (SVM) requirements
- Trident installation and backend configuration requirements
- Supported protocols and data planes per Trident driver
- The StorageClass contract for NetApp-backed tiers

In the meantime, see
[guides/csp-managed-netapp-shared.md](../guides/csp-managed-netapp-shared.md)
for the profile that uses this provider, and the
[installation guide](../../guides/installation/customer-install-guide.md) for
general storage prerequisites.
